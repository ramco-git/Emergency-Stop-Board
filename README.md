# Emergency-Stop-Board　
パワーリレーDG85Bを使用した、駆動電源管理ボードです。


| 機能 | 個数 | ピンアサイン | コネクタ | 備考 |
|-:|-|-|
| 電源入力 | 1 | GND(1ピン) 入力+(2ピン) | ディーンズコネクタ(T型コネクタ) | |
| 電源出力 | 5 | GND(1ピン) 出力+(2ピン) | XT60,ディーンズコネクタ(T型コネクタ) | |
| 制御電源 | 1 | 12V(1ピン) 5V(2ピン) GND(3ピン) | B03B-SXH | 制御電源と駆動電源のGNDは絶縁されている |
| 非常停止入力 | 3 |
